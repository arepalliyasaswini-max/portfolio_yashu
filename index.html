VLSI & Flash Controller

Parametric Non-Volatile Flash Memory Controller

Designed and verified a synchronous behavioral NOR-type Flash memory controller in Verilog HDL using Xilinx Vivado. Modeled a 3-state FSM to schedule multi-cycle latencies for program and sector-erase tasks with bitwise-AND hardware interlocks. Developed a 32-byte address decoding masking array ensuring isolated sector clearing.

Memory & High-Frequency Logic

High-Performance 1Gb RAM Architecture (100 MHz)

Modeled and verified a high-speed 1Gb RAM architecture operating at a 100 MHz clock frequency. Designed memory array control logic, optimized wordline/bitline addressing paths for low latency, and managed strict timing constraints to guarantee zero data corruption during synchronous access.
